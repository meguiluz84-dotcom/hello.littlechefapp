# Little Chef

App educativa de recetas para niños no lectores. Fomentando su autonomía y habilidades motrices.

## Descripción

Little Chef es una aplicación interactiva diseñada para niños en edad preescolar y primaria, especialmente para aquellos que aún no dominan la lectura. A través de interfaz visual intuitiva con iconos, imágenes y sonidos, los niños pueden aprender a preparar recetas simples de forma independiente.

## Características Principales

- 🎨 Interfaz visual amigable con iconos grandes y coloridos
- 🔊 Instrucciones de audio para guiar a los niños
- 👨‍🍳 Recetas interactivas paso a paso
- 🎯 Desarrollo de habilidades motrices finas
- 📱 Diseño responsivo para tablets y dispositivos móviles

## Instalación

```bash
git clone https://github.com/meguiluz84-dotcom/hello.littlechefapp.git
cd hello.littlechefapp
npm install
```

## Uso

```bash
npm start
```

La aplicación se abrirá en tu navegador en `http://localhost:3000`
